# DavydovFoldon API

The public API is exported by `DavydovFoldon`. `run_soliton` produces a
`Trajectory`; `compute_2DIR_spectrum` transforms it into a waiting-time series
of absorptive spectra; and `save_trajectory` writes the documented HDF5 schema.

The model is a testable computational hypothesis. Its output is not evidence
that biological proteins use Davydov solitons and should be compared against
appropriate null models and experimental controls.
